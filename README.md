# IvaFluud — C++ compiler playground

Онлайн-компилятор C++ с редактором, stdin и выводом программы.

## Просто файл (без установки)

Откройте **`IvaFluud.html`** двойным кликом в браузере. Нужен интернет (компиляция через Wandbox).

## Локальный сервер (g++)

Требования: Node.js 18+, `g++` в `PATH`.

```bash
node server.js
```

Откройте http://127.0.0.1:3847

Горячая клавиша: **Ctrl+Enter** (или **⌘+Enter**) — скомпилировать и выполнить.

## Возможности

- Стандарты C++17 / C++20 / C++23
- Примеры программ
- Поле stdin для `cin`
- stdout / stderr и код выхода
- Лимиты: 64 КБ исходника, 8 с на компиляцию, 4 с на выполнение
