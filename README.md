# FORGE — C++ compiler playground

Онлайн-компилятор C++ с редактором, stdin и выводом программы. Код собирается локально через `g++` и сразу запускается.

## Требования

- Node.js 18+
- `g++` в `PATH` (GCC)

## Запуск

```bash
node server.js
```

Откройте http://127.0.0.1:3847

Горячая клавиша: **Ctrl+Enter** (или **⌘+Enter**) — скомпилировать и выполнить.

## Возможности

- Стандарты C++17 / C++20 / C++23
- Примеры программ
- Поле stdin для `cin`
- stdout / stderr и код выхода
- Лимиты: 64 КБ исходника, 8 с на компиляцию, 4 с на выполнение
