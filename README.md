# ЮгПуть — лендинг

Статическая вёрстка сайта [yugput.ru](https://yugput.ru/): ультразвуковая дефектоскопия путей необщего пользования.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Структура

- `index.html` — главная страница
- `privacy.html` — политика обработки персональных данных
- `css/tailwind.css` — стили макета
- `js/main.js` — модалка заявки, маска телефона, sticky CTA, анимации появления
- `assets/` — логотип, hero и фото секций
